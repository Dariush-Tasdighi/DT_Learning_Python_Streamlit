## For Running Project

```shell
streamlit run ./streamlit_app.py
```

```shell
python -m streamlit run ./streamlit_app.py --server.address 0.0.0.0 --server.port 8000
```

## Enable 'Open Integrated Browser' in VSCode

- CTRL + SHIFT + P
  - Search: 'Browser'
    - Select: Browser: 'Open Integrated Browser'
- [OR]
- In 'Open Quick Access'
  - Search: '> Browser'
    - Select: Browser: 'Open Integrated Browser'
- Then
  - Write the '<http://localhost:8501>' in address bar
    - Install: 'Help agents write better apps'
